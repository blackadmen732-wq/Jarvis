## What this is
A self-hosted AI hub assembled from open source, not custom app code:
- `docker-compose.yml`: Open WebUI (hub, port 3000) + Ollama (own models).
- Cloud providers are OpenAI-compatible connections: OpenRouter, Gemini, z.ai. Keys come from `.env` (first start only; afterwards from Admin → Settings → Connections).
- `scripts/add-model.sh`: pull / import / list / remove Ollama models.
- `theme/custom.css`: dark navy + cyan look, mounted into Open WebUI at /app/build/static/custom.css. Do not replace Open WebUI logos (license).
- `router/Dockerfile`: free-claude-code (FCC, AGPL-3.0) from PyPI, pinned by `FCC_VERSION`. Port 8082 on 127.0.0.1 only. Reads model choices + keys from `.env` (`MODEL`, `MODEL_HAIKU`, `MODEL_FALLBACKS`, `REASONING_*`). Local models need reasoning `off` or they think for minutes on CPU.
- Do NOT add 9router or anything that pools subscription logins / rotates accounts (ToS + ban risk). Mark asked for free; keep to official free tiers, local models, or paid APIs.
- `hud/`: Jarvis HUD (port 3001, 127.0.0.1 only). `server.js` = dependency-free Node server: streams from the router's `/v1/messages` with `thinking: disabled` (keeps local + Kimi fast), parses voice/text commands (switch, council on/off, status, list), runs council rounds, falls back to `fallback` model. `public/hud.js` = state, panels, chat stream, voice (Web Speech API + Voice Studio), FX sounds, decipher/boot effects, 2D canvas fallback. `public/scene3d.js` = three.js 0.170.0 scene (vendored in `public/vendor`, import map in index.html) reading `window.JarvisHUD.getFrame()` each frame. Test in headless Chromium with `--use-gl=angle --use-angle=swiftshader` (slow, ~5 fps, fine for screenshots). Mark asked to REMOVE the jellyfish (not Jarvis-like); `public/holo.js` replaced them (gear-ring machine, wireframe drones, radar sweep). `scenes.js` = scene registry + brain + stream; `blackhole.js` = ray-marched black hole (disk + shadow + photon ring, no sky lensing) rendered at reduced res into a HalfFloat target, drawn as background quad, plus orbiting planets; `sun.js` = sun core. Themes (THEMES in scene3d.js + THEME_UI in hud.js) drive all colours. Live link: warm themes = solar-flare tube looping round the active node, cool themes = Line2 plasma lightning. Deep Space scene was removed (weak). Post-processing = pmndrs/postprocessing 6.39.6 vendored (`vendor/postprocessing.js`, import map) with MSAA 4x + SMAA, mipmap bloom, AgX tone mapping, vignette, grain (renderer.toneMapping must stay NoToneMapping). Backdrop = `sky.js`: ESO Milky Way (`assets/milkyway*.jpg`, CC BY 4.0, credit in README + assets/CREDITS.txt) colour-graded blue/violet, 3 star layers, nebula, ringed planet, mouse parallax. Mark does NOT want the black hole to warp the sky: blackhole.js outputs premultiplied alpha (disk/shadow/ring only) over the sky. Models orbit individually (Kepler w ~ R^-1.5, per-node group rotation; council beams are Line2 rebuilt from world positions). Link switches show a LINK TRANSFER card (linkCard() in hud.js). Black hole v3: RIN 2.6 / ROUT 15 (units rs=1), BASE_SCALE 0.36 world/rs, thick volumetric envelope + polar jets (uJet), uFeed (flare from fed matter), uDensity (Plasma slider), shadow writes depth (bg quad gl_FragDepth, depthFunc Always) so objects behind it are hidden, sky dims in BH mode, adaptive resolution when frames are slow. `bhplay.js` = Play mode (light rays with the same bending law, Paczynski-Wiita matter, tidal disruption, drag/fling of orbiting planets + holo drones via adopt(); camera views Wide/Close/Follow in scene3d.js); while the play bar is open Auto keeps the black hole (f.playOpen). Research shortlist for more realism (not yet used): Adriwin06/black-hole (MIT, accretion.glsl, Planck LUT; its milkyway.jpg is CC BY-NC, do not copy), three.js GPUComputationRenderer (MIT) for 100k+ GPU particles, ebruneton/black_hole_shader (BSD-3), rreusser kerr-geodesics (MIT). Radar sweep only shows when the floor is visible. Logo = `assets/logo.svg` (Mark's gold double-parallelogram icon). Control-room readouts in index.html (.readout) are filled by updateReadouts() in hud.js with real data. `cores.js` = extra core faces (circuit, pulse, portal, plasma, liquid, bloom = GPU-animated iridescent fibre flower); scene 'auto' (default) maps uiState -> face (idle=home core, listening=pulse, thinking=portal, speaking=plasma, council=liquid); hud.js stores `scene2` + `home` in localStorage. Studio voices: `voice` service = Kokoro-FastAPI `kokoro-fastapi-cpu:v0.10.0`; HUD server proxies `/api/voices` + `/api/tts` (Kokoro ids like `bm_george`: 1st letter accent, 2nd f/m). Favourites in `hud/models.json`. Keep the look: amber core, red routes, blue nodes, glass panels with amber corner brackets.
- Router's non-streaming `/v1/chat/completions` hits a "Decimal is not JSON serializable" bug for Groq/Cerebras/Ollama in FCC 6.19.46; use streaming `/v1/messages` instead.
- `lina/`: Lina Sigra checker service (Python stdlib, no host port; HUD reaches it at `LINA_URL`). `engine/` is copied from Edge Bot `backtest/lina` (lang.py 0.4, lina_sigra.py, lexicon, train.py for the writer prompt); refresh with `scripts/update-lina.sh`. HUD: "Lina rule: ..." -> `lina_writer` model (models.json) writes one line with Lina's own grammar prompt (`/prompt`), `/check` decides, one retry with the error, then "confirm" appends to `DATA_DIR/rules.lina`. The writer's raw line is shown, never spoken (role `lina`). "How did the bots do" reads Edge Bot's public `parallax-money?view=training` (`EDGEBOT_URL`).
- HUD security gate (`allowed()` in server.js): Host must be localhost/127.0.0.1/[::1]:PORT (or `HUD_ALLOWED_HOSTS`), a foreign or `null` Origin is refused, POSTs must be `application/json`. Blocks cross-site "simple" POSTs and DNS rebinding. Keep it.
- `hands/hands.js`: Jarvis Hands, runs on the HOST (not Docker), Node 18+, no deps. 127.0.0.1:3003 (3002 is laptop control); only Origin localhost:3001/127.0.0.1:3001; pairing token in `~/.jarvis-hands/token` sent as `x-jarvis-token`; `/info`, `/run` (cwd = work folder, 60 s timeout, output clipped), `/open` (http/https only); JSONL log. Steps run straight away (Mark's decision, Nov 22: no confirm step, no built-in blocks). `LOCKED` in hands.js is Mark's own rule list, empty by default: don't fill it for him. The HUD SERVER plans (model returns one JSON step, `HANDS_RULES`), checks Mark's LOCKED list (the hud image copies hands.js; build context is the repo root) and sends `hands_run`; the BROWSER page calls Hands, then posts `hands_result` for a spoken summary. Keep the connection guard (127.0.0.1, HUD Origin, pairing code): it stops other websites, not Mark.
- Personality: `state.personality` 'grok' (default, `jarvis/jarvis-persona-grok.md`, Mark asked for Jarvis to be like Grok) or 'classic' (`jarvis-persona.md`); voice "Grok mode"/"rebel mode" and "serious mode" ("classic mode"/"normal mode" are scene words). Real Grok: `open_router/x-ai/grok-4.7` and `grok-4.3` in models.json (paid). Speech-to-text writes "Groq" as "Grok", so "switch to grok" goes to xAI Grok; Groq stays reachable as "gpt", "fast", "gpt oss".
- `hands/agents.js`: agent team (Mark's request after the Grok Bot clone video). Loaded by hands.js on the host. Agent = name, role, model (router id, the HUD's active model at hire time), routine (`every_minutes` or `at` HH:MM). Run = up to AGENT_MAX_STEPS JSON steps (run/open/done) via the router at ROUTER_URL (127.0.0.1:8082 on the host), cwd `~/jarvis-workspace/agents/<id>`, LOCKED checked, saved to `~/.jarvis-hands/runs/`. Scheduler ticks every 30 s. Endpoints: GET /agents, GET /runs, POST /agents, /agents/delete, /agents/run. HUD: parseRoutine + 'agent' command; the browser calls Hands, polls /runs, and announces routine results (first poll only primes).
- Sophia (Nov 22): second assistant. Server `state.assistant` 'jarvis'|'sophia', `activeBy` keeps each one's model; `pickAssistant()` handles "Sophia, ..." / "talk to Jarvis"; persona `jarvis/sophia-persona.md` (Grok style; serious mode = jarvis-persona.md with the name swapped). - Compose profiles: `hub` (open-webui) and `voices` (kokoro) are opt-in (`COMPOSE_PROFILES`); default start = ollama, router, lina, hud. `OLLAMA_KEEP_ALIVE` 2m. WEBUI_SECRET_KEY is no longer required unless the hub is on.

Auto: listening = liquid, thinking = portal, speaking = plasma, council = brain. The render code for them still exists in cores.js / scenes.js but is never selected.
- App mode (Nov 22, Mark doesn't want the terminal): `scripts/install-app.sh` writes `~/.local/share/applications/jarvis-os.desktop` (icon `hud/public/assets/icon-512.png`, rendered from logo.svg); it runs `scripts/jarvis-launch.sh` = docker compose up if the HUD doesn't answer, start Hands with nohup if not running, wait, then xdg-open `http://localhost:3001/#hands=<token>`. hud.js stores that token and strips it with `window.history.replaceState` (plain `history` is the chat array in hud.js). `manifest.webmanifest` makes the HUD installable.
